# x_bot description

This package contains the x_bot URDF/xacro and meshes. Mesh URIs remain `package://x_bot/meshes/...`.

Controller parameters belong to `x_bot_control`; MoveIt configuration to `x_bot_moveit_config`; simulation backends to `x_bot_isaac` and `x_bot_gazebo`. Use the workspace root launchers documented in README.
